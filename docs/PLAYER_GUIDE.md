# 玩家快速上手（草稿）

這份是給一般玩家的說明，目標是不用碰任何設定檔就能用。上架前還需要決定發佈的語言版本，見文末。

## 這是什麼

讓你已經在用的 AI 助理（例如 Claude Code）幫你把 RimWorld 1.7 的模組翻成中文。
- 工具本身不連任何 AI 服務，也不需要 API 金鑰。
- 翻譯結果是一個獨立的模組「Agent Translation Pack」，不會修改任何原模組。刪掉它，翻譯就完全移除。
- 已經有人翻好的部分（模組自帶的中文、翻譯補丁）會保留，不會被蓋掉。

> 隱私：要翻譯的模組文字會送到你所使用 AI 助理的服務商。

## 三個步驟

### 1. 安裝橋接模組（建議）

訂閱「Agent Translation Bridge」，在模組清單啟用即可，位置不限。

它會在遊戲裡確認每一筆譯文是否真的生效。結果在「選項 → 模組設定 → Agent Translation」。

### 2. 安裝 rwat，連到你的 AI 助理

從專案的發佈頁下載 `rwat.exe`，放在任何資料夾。以 Claude Code 為例，執行一次：

```bash
claude mcp add rimworld-translation -- "C:\你放的位置\rwat.exe" serve
```

其他支援 MCP 的助理，設定方式相同：指令是 `rwat.exe`，參數是 `serve`。

rwat 會自己找到遊戲資料夾、Workshop 資料夾和你的模組清單。

### 3. 請助理翻譯

先在遊戲裡把語言設成簡體中文或繁體中文，並關閉遊戲一次，讓設定存檔。翻譯包的語言會自動跟著遊戲語言。

然後對助理說，例如：

> 幫我把啟用中、還沒有中文的模組翻譯好，最後建置翻譯包。

完成後重新啟動遊戲，在模組清單啟用「Agent Translation Pack」。它會自動排在被翻譯的模組之後。

如果已經開啟了橋接模組的重載選項，介面文字（Keyed）不必重開遊戲也能更新。

## 選用功能（預設關閉，只有你能開）

| 功能 | 在哪裡開 | 說明 |
|---|---|---|
| 不重開遊戲更新介面文字 | 遊戲內「模組設定 → Agent Translation」 | 實驗性；物品名稱與描述仍需重開遊戲 |
| 補上模組漏定義的鍵 | `config.json` 的 `code_keys.enabled` | 有些模組的介面連英文都顯示成 `Some.Key.Name`。開啟後助理會依鍵名推測譯文，每筆都會標示為推測 |
| 自動採用既有的簡中譯文（繁中模式） | `config.json` 的 `simplified_auto_adopt.enabled` | 依你設定的條件，把現成的簡中譯文轉成繁中直接使用 |

`config.json` 在 `%LOCALAPPDATA%\RimWorldAgentTranslation\`。助理沒辦法替你打開這些選項。

## 常見問題

- **翻譯沒出現**：
  - 確認遊戲語言和翻譯包的語言相同。
  - 確認「Agent Translation Pack」已啟用。
  - 橋接模組的設定頁會列出哪些模組的譯文沒有生效、被誰覆蓋。
- **想換成另一種中文**：在遊戲裡切換語言，重新啟動助理，再請它重新建置翻譯包。
- **移除**：刪除 Mods 資料夾裡的 `!AgentTranslation_Pack`，要的話也一併刪除 `!AgentTranslation_Bridge`。
