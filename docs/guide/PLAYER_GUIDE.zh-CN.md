# RimWorld Agent Translation 玩家指南（简体中文）

其他语言：[繁體中文](PLAYER_GUIDE.zh-TW.md) · [English](PLAYER_GUIDE.en.md) · [日本語](PLAYER_GUIDE.ja.md) · [한국어](PLAYER_GUIDE.ko.md)

## 这是什么

这个工具让你平时用的 AI 助手（例如 Claude）把 RimWorld 1.7 的模组翻译成你的语言。原文是什么语言都可以，可以翻译成游戏内置的任何语言。

| 支持程度 | 语言 |
|---|---|
| 完整支持 | 简体中文、繁体中文、日语、韩语、英语 |
| 实验性（只检查格式） | 游戏内置的其他语言：德语、法语、俄语、西班牙语等 |

- 工具本身不连接任何 AI 服务，也不需要 API 密钥，翻译由你自己的 AI 助手完成。
- 有英文的模组从英文翻译。只有其他语言的模组（例如只有中文的模组）也能翻译成英语或其他语言。
- 翻译结果是一个独立的模组“Agent Translation Pack”。不会修改任何原始模组，删除这个翻译包，所有翻译就被移除。
- 已有的翻译会保留，不会被覆盖，包括模组自带的翻译和汉化补丁。

> 隐私：要翻译的模组文本会发送给你所使用的 AI 助手的服务商。

## 需要什么

- RimWorld 1.7，并且至少启动过一次游戏。
- 支持 MCP 的 AI 助手，例如 Claude 桌面版。

## 三个步骤

### 1. 安装桥接模组（建议）

在创意工坊订阅“Agent Translation Bridge”，在模组列表里启用，放在任何位置都可以。它会：
- 提供一个设置页，里面有简短教学、翻译状态和翻译包语言；
- 在游戏里检查每条翻译是否真的生效；
- 加上两个快捷按钮，点一下就会打开设置页：一个是右下角图标列的小图标（需要 Harmony 模组），一个是底部分页栏的小按钮。两个都可以在设置页隐藏。

### 2. 安装 rwat 并连接 AI 助手

从项目的发布页下载 `rwat.exe`，放在固定的文件夹，例如 `D:\Tools\rwat\`。

想确认文件没被篡改，可以在 PowerShell 运行下面这行，结果要和发布页的 `SHA256SUMS.txt` 一致：

```
Get-FileHash rwat.exe -Algorithm SHA256
```

**Claude 桌面版**：
1. 打开“Settings > Developer > Edit Config”。
2. 加入下面的内容，`command` 改成你放 rwat.exe 的位置。
3. 保存后重启 Claude。

```json
{
  "mcpServers": {
    "rimworld-translation": { "command": "D:\\Tools\\rwat\\rwat.exe", "args": ["serve"] }
  }
}
```

Claude 桌面版的 Code 分页也会使用这份配置，所以只需要在一个地方配置。

**Claude Code**：运行这一行。

```
claude mcp add rimworld-translation -- "D:\Tools\rwat\rwat.exe" serve
```

**其他 MCP 客户端**：配置方式相同，命令是 `rwat.exe`，参数是 `serve`。

rwat 会自己找到游戏文件夹、创意工坊文件夹和你的模组列表。

### 3. 请 AI 助手翻译

翻译包语言默认跟随游戏语言。先在游戏里设置好语言，然后关闭一次游戏，让设置保存下来。接着对 AI 助手说，例如：

> 帮我把已启用、还没有我的语言的模组翻译好，然后建置翻译包。

完成后重启游戏，在模组列表启用“Agent Translation Pack”。它会自动排在被翻译的模组后面。

## 设置页

用快捷按钮，或从“选项 → 模组设置 → Agent Translation”打开。

**简单模式**（默认）只显示大多数玩家需要的内容：
- 三步教学；
- 当前状态：有多少条翻译生效，以及下一步该做什么；
- 翻译包语言（下拉菜单，大多数玩家选“跟随游戏语言”即可）；
- 两个快捷按钮的开关。

**进阶模式**另外显示：

| 设置 | 默认 | 说明 |
|---|---|---|
| 生成运行时报告 | 开 | 检查哪些翻译生效了 |
| 允许不重启游戏重新加载 Keyed 译文 | 关 | 实验性，只更新界面文本；名称和描述仍需重启游戏 |
| 补上模组漏定义的键 | 关 | 有些模组连英文都显示成 `Some.Key.Name` 这类键名。开启后 AI 助手会根据键名推测译文，每条都会标记为推测 |
| 繁体模式：自动采用现成的简体译文 | 关 | 把现成的简体译文转换为繁体后直接使用，条件可以在 config.json 中调整 |

- 进阶模式也会显示完整报告。
- 快捷按钮和游戏内检查的开关立即生效。
- 翻译包语言和最后两个开关会保存到 rwat 的设置文件，重新启动 AI 助手后生效；AI 助手不能替你修改。
- 设置文件位置：`%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\AgentTranslation\config.json`，就在游戏的 `Saves`、`Config` 旁边。

## 常见问题

- **翻译没有出现**：
  - 游戏语言要和翻译包语言一致。
  - 要启用“Agent Translation Pack”。
  - 设置页会写出下一步该做什么；进阶模式会列出哪些模组的翻译没有生效。
- **切换语言**：在设置页选择语言（或修改游戏语言），重新启动 AI 助手，请它重新建置翻译包，再重启游戏。
- **实验性语言**：会检查占位符、标记和换行，但没有该语言专用的检查，请在游戏里看一下结果。
- **移除**：删除 Mods 文件夹里的 `!AgentTranslation_Pack`。如果想清理干净，也可以取消订阅桥接模组，并删除上面提到的 `AgentTranslation` 文件夹。
- **质量**：翻译由机器生成，没有经过人工校对。可以请 AI 助手多用翻译记忆或词汇表，让用词保持一致。
