# RimWorld Agent Translation プレイヤーガイド（日本語）

ほかの言語：[繁體中文](PLAYER_GUIDE.zh-TW.md) · [简体中文](PLAYER_GUIDE.zh-CN.md) · [English](PLAYER_GUIDE.en.md) · [한국어](PLAYER_GUIDE.ko.md)

## これは何か

いつも使っている AI アシスタント（Claude など）に、RimWorld 1.7 のモッドをあなたの言語へ翻訳してもらうためのツールです。原文の言語は問わず、ゲームに入っているどの言語にも翻訳できます。

| 対応 | 言語 |
|---|---|
| 正式対応 | 日本語、韓国語、簡体字中国語、繁体字中国語、英語 |
| 実験的（形式のチェックのみ） | ゲームに入っているほかの言語：ドイツ語、フランス語、ロシア語、スペイン語など |

- ツール自体は AI サービスに接続せず、API キーも不要です。翻訳はあなたの AI アシスタントが行います。
- 英語があるモッドは英語から翻訳します。英語がないモッド（中国語だけのモッドなど）も、英語やほかの言語に翻訳できます。
- 翻訳結果は別のモッド「Agent Translation Pack」になります。元のモッドは一切変更しません。翻訳パックを削除すれば、翻訳はすべて取り除けます。
- すでにある翻訳（モッド同梱の翻訳や翻訳パッチ）はそのまま残り、上書きされません。

> プライバシー：翻訳するモッドの文章は、お使いの AI アシスタントの提供元に送信されます。

## 必要なもの

- RimWorld 1.7（一度以上起動したことがあること）。
- MCP に対応した AI アシスタント（Claude デスクトップアプリなど）。

## 3 つの手順

### 1. ブリッジモッドを入れる（推奨）

ワークショップで「Agent Translation Bridge」をサブスクライブし、モッド一覧で有効にします（順番はどこでも構いません）。このモッドは次のことをします。
- かんたんな使い方、翻訳の状態、翻訳パックの言語をまとめた設定ページを表示します。
- 各翻訳がゲーム内で実際に反映されているかを確認します。
- 設定ページを開くボタンを 2 つ追加します。1 つは右下のアイコン列の小さなアイコン（Harmony モッドが必要）、もう 1 つは下部のタブバーの小さなボタンです。どちらも設定ページで非表示にできます。

### 2. rwat を入れて AI アシスタントに接続する

プロジェクトのリリースページから `rwat.exe` をダウンロードし、決まったフォルダー（例：`D:\Tools\rwat\`）に置きます。

ファイルが改ざんされていないか確かめるには、PowerShell で次を実行します。結果がリリースページの `SHA256SUMS.txt` と一致すれば問題ありません。

```
Get-FileHash rwat.exe -Algorithm SHA256
```

**Claude デスクトップアプリ**：
1. 「Settings > Developer > Edit Config」を開きます。
2. 次の内容を追加し、`command` を rwat.exe を置いた場所に書き換えます。
3. 保存して Claude を再起動します。

```json
{
  "mcpServers": {
    "rimworld-translation": { "command": "D:\\Tools\\rwat\\rwat.exe", "args": ["serve"] }
  }
}
```

Claude デスクトップアプリの Code タブもこの設定を使うので、設定は 1 か所だけにしてください。

**Claude Code**：次の 1 行を実行します。

```
claude mcp add rimworld-translation -- "D:\Tools\rwat\rwat.exe" serve
```

**ほかの MCP クライアント**：設定方法は同じです。コマンドは `rwat.exe`、引数は `serve` です。

rwat はゲームフォルダー、ワークショップフォルダー、モッド一覧を自動で見つけます。

### 3. AI アシスタントに頼む

翻訳パックの言語は、標準ではゲームの言語に合わせます。先にゲームの言語を設定し、設定を保存するために一度ゲームを終了してください。それから AI アシスタントに、たとえば次のように頼みます。

> 有効なモッドのうち、まだ日本語がないものを翻訳して、翻訳パックを作って。

終わったらゲームを再起動し、モッド一覧で「Agent Translation Pack」を有効にします。翻訳したモッドより後ろに自動で並びます。

## 設定ページ

ボタンを押すか、「オプション → モッド設定 → Agent Translation」から開きます。

**かんたんモード**（標準）では、多くのプレイヤーに必要な項目だけを表示します。
- 3 ステップの使い方
- 現在の状態（反映されている翻訳の数と、次にすること）
- 翻訳パックの言語（メニュー。ほとんどの場合「ゲームの言語に合わせる」で大丈夫です）
- 2 つのボタンの表示切り替え

**詳細モード**では、さらに次の項目を表示します。

| 設定 | 標準 | 説明 |
|---|---|---|
| 実行時レポートを書き出す | オン | どの翻訳が反映されているかを確認します |
| 再起動せずに Keyed の訳を読み込み直せるようにする | オフ | 実験的。UI の文字列だけを更新します。名前や説明は再起動が必要です |
| モッドが定義し忘れたキーも翻訳する | オフ | 英語でも `Some.Key.Name` のようなキー名がそのまま表示されるモッドがあります。オンにすると AI アシスタントがキー名から文を推測し、すべて推測として印が付きます |
| 繁体字モード：既存の簡体字訳を自動で採用 | オフ | 既存の簡体字訳を繁体字に変換してそのまま使います。条件は config.json で調整できます |

- 詳細モードでは詳しいレポートも表示されます。
- ボタンとゲーム内チェックの設定はすぐに反映されます。
- 翻訳パックの言語と最後の 2 つの設定は rwat の設定ファイルに保存され、AI アシスタントを再起動すると反映されます。AI アシスタントが代わりに変更することはできません。
- 設定ファイルの場所：`%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\AgentTranslation\config.json`（ゲームの `Saves` と `Config` の隣）。

## よくある質問

- **翻訳が表示されない**：
  - ゲームの言語と翻訳パックの言語が同じか確認してください。
  - 「Agent Translation Pack」が有効か確認してください。
  - 設定ページに次にすることが表示されます。詳細モードでは、翻訳が反映されていないモッドの一覧が見られます。
- **言語を変える**：設定ページで言語を選ぶ（またはゲームの言語を変える）→ AI アシスタントを再起動 → 翻訳パックを作り直してもらう → ゲームを再起動、の順に行います。
- **実験的な言語**：プレースホルダー、タグ、改行はチェックしますが、その言語専用のチェックはありません。ゲーム内で結果を確認してください。
- **削除**：Mods フォルダーの `!AgentTranslation_Pack` を削除します。必要ならブリッジモッドのサブスクライブも解除し、上記の `AgentTranslation` フォルダーも削除してください。
- **品質**：翻訳は機械によるもので、人による校正はしていません。用語をそろえたいときは、翻訳メモリや用語集を使うよう AI アシスタントに頼んでください。
