# RimWorld Agent Translation プレイヤーガイド（日本語）

他の言語：[繁體中文](PLAYER_GUIDE.zh-TW.md) ・ [简体中文](PLAYER_GUIDE.zh-CN.md) ・ [English](PLAYER_GUIDE.en.md) ・ [한국어](PLAYER_GUIDE.ko.md)

## これは何か

すでに使っている AI アシスタント（例：Claude）に、RimWorld 1.7 の MOD を翻訳させるツールです。

> **現在の翻訳先は簡体字中国語と繁体字中国語のみです。** 日本語への翻訳は今後対応予定で、まだ利用できません。

- ツール自体は AI サービスに接続せず、API キーも不要です。翻訳はあなたのアシスタントが行います。
- 翻訳結果は独立した MOD「Agent Translation Pack」になります。元の MOD は一切変更しません。削除すれば翻訳は完全に取り除かれます。
- 既存の翻訳（MOD に同梱された訳、翻訳パッチ）は残され、上書きされません。

> プライバシー：翻訳する MOD のテキストは、あなたが使う AI アシスタントの提供元に送信されます。

## 必要なもの

- RimWorld 1.7（一度以上起動済みであること）。
- MCP に対応した AI アシスタント（例：Claude デスクトップアプリ）。

## 3 つの手順

### 1. ブリッジ MOD を導入する（推奨）

「Agent Translation Bridge」をサブスクライブし、MOD リストで有効にします。並び順はどこでも構いません。この MOD は次のことをします。
- 各翻訳がゲーム内で実際に反映されているかを確認する。
- ツールの設定ページを追加する：「オプション → MOD 設定 → Agent Translation」。

### 2. rwat を導入し、アシスタントに接続する

プロジェクトのリリースページから `rwat.exe` をダウンロードし、決まったフォルダ（例：`D:\Tools\rwat\`）に置きます。

リリースページの `SHA256SUMS.txt` で、ファイルが改ざんされていないか確認できます。PowerShell で次を実行してください。

```
Get-FileHash rwat.exe -Algorithm SHA256
```

結果が `SHA256SUMS.txt` の値と一致すれば問題ありません。

**Claude デスクトップアプリ（チャット）**：
1. 「設定 → 開発者 → 設定を編集」を開きます。
2. 次の内容を追加し、`command` を rwat.exe の場所に変えます。
3. 保存して Claude を再起動します。

```json
{
  "mcpServers": {
    "rimworld-translation": { "command": "D:\\Tools\\rwat\\rwat.exe", "args": ["serve"] }
  }
}
```

**Claude Code**：次の 1 行を実行します。

```
claude mcp add rimworld-translation -- "D:\Tools\rwat\rwat.exe" serve
```

**その他の MCP クライアント**：設定方法は同じです。コマンドは `rwat.exe`、引数は `serve` です。

rwat はゲームフォルダ、ワークショップフォルダ、MOD リストを自動で見つけます。

### 3. アシスタントに依頼する

ゲームの言語を簡体字または繁体字中国語にし、設定を保存するために一度ゲームを終了します。翻訳パックの言語は、既定ではゲームの言語に合わせて決まります。

その後、アシスタントに例えば次のように伝えます。

> 有効な MOD のうち、まだ中国語がないものを翻訳して、最後に翻訳パックをビルドしてください。

完了したらゲームを再起動し、MOD リストで「Agent Translation Pack」を有効にします。翻訳対象の MOD の後ろに自動で並びます。

## 設定（すべてゲーム内）

「オプション → MOD 設定 → Agent Translation」を開きます。

| 設定 | 既定 | 説明 |
|---|---|---|
| 実行時レポートを作成 | オン | どの翻訳が反映されているかを確認し、同じページに表示します |
| 再起動せずに UI テキストを再読み込み | オフ | 実験的機能です。UI テキスト（Keyed）のみ更新し、アイテム名と説明文には再起動が必要です |
| 翻訳パックの言語 | ゲームに合わせる | 簡体字・繁体字に固定することもできます |
| MOD が定義し忘れたキーを補う | オフ | 一部の MOD は英語でもキー名（例：`Some.Key.Name`）がそのまま表示されます。オンにすると、アシスタントがキー名から訳を推測します。推測した訳には印が付きます |
| 繁体字モード：既存の簡体字訳を自動採用 | オフ | 既存の簡体字訳を繁体字に変換して直接使います（条件は config.json で調整可能） |

- 下の 3 項目は rwat の設定ファイルに保存され、アシスタントを再起動すると反映されます。
- アシスタントがこれらを勝手にオンにすることはできません。
- 上級者は設定ファイルを直接編集することもできます：`%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\AgentTranslation\config.json`。ゲームの `Saves`、`Config` と同じ階層にあります。

## よくある質問

- **翻訳が表示されない**：
  - ゲームの言語と翻訳パックの言語が同じか確認してください。
  - 「Agent Translation Pack」が有効か確認してください。
  - ブリッジ MOD の設定ページには、翻訳が反映されていない MOD と、上書きしている MOD が表示されます。
- **削除**：Mods フォルダの `!AgentTranslation_Pack` を削除します。必要ならブリッジ MOD のサブスクライブも解除し、上記の `AgentTranslation` フォルダも削除してください。
- **品質**：翻訳は AI が生成したもので、人による校正はされていません。
