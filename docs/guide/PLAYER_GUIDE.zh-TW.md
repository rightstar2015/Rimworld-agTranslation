# RimWorld Agent Translation 玩家指南（繁體中文）

其他語言：[简体中文](PLAYER_GUIDE.zh-CN.md) · [English](PLAYER_GUIDE.en.md) · [日本語](PLAYER_GUIDE.ja.md) · [한국어](PLAYER_GUIDE.ko.md)

## 這是什麼

這個工具讓你平常用的 AI 助理（例如 Claude）把 RimWorld 1.7 的模組翻成你的語言。原文是什麼語言都可以，可以翻成遊戲內建的任何語言。

| 支援程度 | 語言 |
|---|---|
| 完整支援 | 簡體中文、繁體中文、日文、韓文、英文 |
| 實驗性（只檢查格式） | 遊戲內建的其他語言：德文、法文、俄文、西班牙文等 |

- 工具本身不連線任何 AI 服務，也不需要 API 金鑰，翻譯由你自己的 AI 助理完成。
- 有英文的模組從英文翻。只有其他語言的模組（例如只有中文的模組）也能翻成英文或其他語言。
- 翻譯結果是另一個獨立的模組「Agent Translation Pack」。不會修改任何原始模組，刪掉這個翻譯包，所有翻譯就移除了。
- 已經有的翻譯會保留，不會被覆蓋，包括模組自帶的翻譯和翻譯補丁。

> 隱私：要翻譯的模組文字會送到你所使用的 AI 助理的服務商。

## 需要什麼

- RimWorld 1.7，並且至少啟動過一次遊戲。
- 支援 MCP 的 AI 助理，例如 Claude 桌面版。

## 三個步驟

### 1. 安裝橋接模組（建議）

在工作坊訂閱「Agent Translation Bridge」，在模組清單裡啟用，放在任何位置都可以。它會：
- 提供一個設定頁，裡面有簡短教學、翻譯狀態和翻譯包語言；
- 在遊戲裡檢查每條翻譯是否真的生效；
- 加上兩個快速按鈕，按了會打開設定頁：一個是右下角圖示列的小圖示（需要 Harmony 模組），一個是底部分頁列的小按鈕。兩個都可以在設定頁隱藏。

### 2. 安裝 rwat 並連上 AI 助理

從專案的發佈頁下載 `rwat.exe`，放在固定的資料夾，例如 `D:\Tools\rwat\`。

想確認檔案沒被竄改，可以在 PowerShell 執行下面這行，結果要和發佈頁的 `SHA256SUMS.txt` 一致：

```
Get-FileHash rwat.exe -Algorithm SHA256
```

**Claude 桌面版**：
1. 打開「Settings > Developer > Edit Config」。
2. 加入下面的內容，`command` 改成你放 rwat.exe 的位置。
3. 存檔後重開 Claude。

```json
{
  "mcpServers": {
    "rimworld-translation": { "command": "D:\\Tools\\rwat\\rwat.exe", "args": ["serve"] }
  }
}
```

Claude 桌面版的 Code 分頁也會使用這份設定，所以只要在一個地方設定。

**Claude Code**：執行這一行。

```
claude mcp add rimworld-translation -- "D:\Tools\rwat\rwat.exe" serve
```

**其他 MCP 客戶端**：設定方式相同，命令是 `rwat.exe`，參數是 `serve`。

rwat 會自己找到遊戲資料夾、工作坊資料夾和你的模組清單。

### 3. 請 AI 助理翻譯

翻譯包語言預設跟著遊戲語言。先在遊戲裡設好語言，然後關一次遊戲，讓設定存檔。接著對 AI 助理說，例如：

> 幫我把啟用中、還沒有我的語言的模組翻譯好，然後建置翻譯包。

完成後重開遊戲，在模組清單啟用「Agent Translation Pack」。它會自動排在被翻譯的模組後面。

## 設定頁

用快速按鈕，或從「選項 → 模組設定 → Agent Translation」打開。

**簡單模式**（預設）只顯示大多數玩家需要的內容：
- 三步驟教學；
- 目前狀態：有幾條翻譯生效，以及下一步該做什麼；
- 翻譯包語言（下拉選單，大多數玩家選「跟著遊戲語言」就好）；
- 兩個快速按鈕的開關。

**進階模式**另外顯示：

| 設定 | 預設 | 說明 |
|---|---|---|
| 產生執行期報告 | 開 | 檢查哪些翻譯有生效 |
| 允許不重開遊戲重新載入 Keyed 譯文 | 關 | 實驗性，只更新介面文字；名稱和描述還是要重開遊戲 |
| 補上模組漏定義的鍵 | 關 | 有些模組連英文都顯示成 `Some.Key.Name` 這類鍵名。開啟後 AI 助理會依鍵名推測譯文，每條都會標示為推測 |
| 繁中模式：自動採用現成的簡中譯文 | 關 | 把現成的簡中譯文轉成繁中直接使用，條件可以在 config.json 調整 |

- 進階模式也會顯示完整報告。
- 快速按鈕和遊戲內檢查的開關立即生效。
- 翻譯包語言和最後兩個開關會存進 rwat 的設定檔，重新啟動 AI 助理後生效；AI 助理不能替你改。
- 設定檔位置：`%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\AgentTranslation\config.json`，就在遊戲的 `Saves`、`Config` 旁邊。

## 常見問題

- **翻譯沒有出現**：
  - 遊戲語言要和翻譯包語言一樣。
  - 要啟用「Agent Translation Pack」。
  - 設定頁會寫出下一步該做什麼；進階模式會列出哪些模組的翻譯沒生效。
- **換語言**：在設定頁選語言（或改遊戲語言），重新啟動 AI 助理，請它重新建置翻譯包，再重開遊戲。
- **實驗性語言**：會檢查佔位符、標記和換行，但沒有該語言專用的檢查，請在遊戲裡看一下結果。
- **移除**：刪掉 Mods 資料夾裡的 `!AgentTranslation_Pack`。如果想清乾淨，也可以取消訂閱橋接模組，並刪除上面提到的 `AgentTranslation` 資料夾。
- **品質**：翻譯由機器產生，沒有經過人工校對。可以請 AI 助理多用翻譯記憶或詞彙表，讓用詞保持一致。
