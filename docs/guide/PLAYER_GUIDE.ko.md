# RimWorld Agent Translation 플레이어 가이드 (한국어)

다른 언어: [繁體中文](PLAYER_GUIDE.zh-TW.md) · [简体中文](PLAYER_GUIDE.zh-CN.md) · [English](PLAYER_GUIDE.en.md) · [日本語](PLAYER_GUIDE.ja.md)

## 이 도구는

이미 사용 중인 AI 어시스턴트(예: Claude)로 RimWorld 1.7 모드를 번역하는 도구입니다.

> **현재 번역 대상 언어는 중국어 간체와 번체뿐입니다.** 한국어 번역은 앞으로 지원할 예정이며 아직 사용할 수 없습니다.

- 도구 자체는 AI 서비스에 접속하지 않으며 API 키도 필요 없습니다. 번역은 여러분의 어시스턴트가 합니다.
- 번역 결과는 별도의 모드 "Agent Translation Pack"으로 만들어집니다. 원본 모드는 전혀 수정하지 않으며, 이 모드를 삭제하면 번역이 완전히 제거됩니다.
- 기존 번역(모드에 포함된 번역, 번역 패치)은 그대로 유지되며 덮어쓰지 않습니다.

> 개인정보: 번역할 모드 텍스트는 사용하는 AI 어시스턴트의 제공업체로 전송됩니다.

## 준비물

- RimWorld 1.7 (한 번 이상 실행한 상태).
- MCP를 지원하는 AI 어시스턴트 (예: Claude 데스크톱 앱).

## 세 단계

### 1. 브리지 모드 설치 (권장)

"Agent Translation Bridge"를 구독하고 모드 목록에서 활성화합니다. 위치는 상관없습니다. 이 모드는 다음 일을 합니다.
- 각 번역이 게임에서 실제로 적용되는지 확인합니다.
- 도구 설정 페이지를 추가합니다: 옵션 → 모드 설정 → Agent Translation.

### 2. rwat 설치 후 어시스턴트에 연결

프로젝트 릴리스 페이지에서 `rwat.exe`를 내려받아 정해진 폴더(예: `D:\Tools\rwat\`)에 둡니다.

릴리스 페이지의 `SHA256SUMS.txt`로 파일이 변조되지 않았는지 확인할 수 있습니다. PowerShell에서 다음을 실행하세요.

```
Get-FileHash rwat.exe -Algorithm SHA256
```

결과가 `SHA256SUMS.txt`의 값과 같아야 합니다.

**Claude 데스크톱 앱 (채팅)**:
1. 설정 → 개발자 → 설정 편집을 엽니다.
2. 아래 내용을 추가하고, `command`를 rwat.exe가 있는 위치로 바꿉니다.
3. 저장한 뒤 Claude를 다시 시작합니다.

```json
{
  "mcpServers": {
    "rimworld-translation": { "command": "D:\\Tools\\rwat\\rwat.exe", "args": ["serve"] }
  }
}
```

**Claude Code**: 다음 한 줄을 실행합니다.

```
claude mcp add rimworld-translation -- "D:\Tools\rwat\rwat.exe" serve
```

**다른 MCP 클라이언트**: 설정 방법은 같습니다. 명령은 `rwat.exe`, 인수는 `serve`입니다.

rwat는 게임 폴더, 창작마당 폴더, 모드 목록을 자동으로 찾습니다.

### 3. 어시스턴트에게 요청

게임 언어를 중국어 간체 또는 번체로 설정한 다음, 설정이 저장되도록 게임을 한 번 종료합니다. 번역 팩의 언어는 기본적으로 게임 언어를 따릅니다.

그다음 어시스턴트에게 이렇게 말합니다.

> 활성화된 모드 중 아직 중국어가 없는 모드를 번역하고, 마지막에 번역 팩을 빌드해 줘.

끝나면 게임을 다시 시작하고 모드 목록에서 "Agent Translation Pack"을 활성화합니다. 번역된 모드 뒤로 자동 정렬됩니다.

## 설정 (모두 게임 안에서)

옵션 → 모드 설정 → Agent Translation을 엽니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| 실행 중 보고서 생성 | 켜짐 | 어떤 번역이 적용되는지 확인하고 같은 페이지에 결과를 표시합니다 |
| 재시작 없이 UI 텍스트 다시 불러오기 | 꺼짐 | 실험적 기능입니다. UI 텍스트(Keyed)만 갱신하며, 아이템 이름과 설명은 재시작해야 합니다 |
| 번역 팩 언어 | 게임 언어를 따름 | 간체 또는 번체로 고정할 수도 있습니다 |
| 모드가 정의하지 않은 키 보완 | 꺼짐 | 일부 모드는 영어에서도 `Some.Key.Name` 같은 키 이름이 그대로 보입니다. 켜면 어시스턴트가 키 이름으로 번역을 추측하며, 추측한 번역에는 표시가 붙습니다 |
| 번체 모드: 기존 간체 번역 자동 채택 | 꺼짐 | 기존 간체 번역을 번체로 변환해 바로 사용합니다 (조건은 config.json에서 조정) |

- 아래 세 항목은 rwat 설정 파일에 저장되며, 어시스턴트를 다시 시작하면 적용됩니다.
- 어시스턴트가 이 항목들을 대신 켤 수는 없습니다.
- 고급 사용자는 설정 파일을 직접 편집할 수도 있습니다: `%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\AgentTranslation\config.json`. 게임의 `Saves`, `Config`와 같은 위치에 있습니다.

## 자주 묻는 질문

- **번역이 보이지 않음**:
  - 게임 언어와 번역 팩 언어가 같은지 확인하세요.
  - "Agent Translation Pack"이 활성화되었는지 확인하세요.
  - 브리지 모드 설정 페이지에 번역이 적용되지 않은 모드와, 덮어쓴 모드가 표시됩니다.
- **제거**: Mods 폴더의 `!AgentTranslation_Pack`을 삭제합니다. 원하면 브리지 모드 구독도 해제하고 위의 `AgentTranslation` 폴더도 삭제하세요.
- **품질**: 번역은 AI가 생성했으며 사람이 교정하지 않았습니다.
