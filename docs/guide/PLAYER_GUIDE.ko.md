# RimWorld Agent Translation 플레이어 가이드(한국어)

다른 언어: [繁體中文](PLAYER_GUIDE.zh-TW.md) · [简体中文](PLAYER_GUIDE.zh-CN.md) · [English](PLAYER_GUIDE.en.md) · [日本語](PLAYER_GUIDE.ja.md)

## 이것은 무엇인가요

평소 사용하는 AI 어시스턴트(예: Claude)가 RimWorld 1.7 모드를 여러분의 언어로 번역하도록 돕는 도구입니다. 원문 언어는 상관없으며, 게임에 들어 있는 어떤 언어로든 번역할 수 있습니다.

| 지원 수준 | 언어 |
|---|---|
| 정식 지원 | 한국어, 일본어, 간체 중국어, 번체 중국어, 영어 |
| 실험적(형식 검사만) | 게임에 들어 있는 다른 언어: 독일어, 프랑스어, 러시아어, 스페인어 등 |

- 도구 자체는 AI 서비스에 연결하지 않으며 API 키도 필요 없습니다. 번역은 여러분의 AI 어시스턴트가 합니다.
- 영어가 있는 모드는 영어에서 번역합니다. 영어가 없는 모드(중국어만 있는 모드 등)도 영어나 다른 언어로 번역할 수 있습니다.
- 번역 결과는 별도의 모드 "Agent Translation Pack"이 됩니다. 원본 모드는 전혀 수정하지 않으며, 번역 팩을 삭제하면 모든 번역이 사라집니다.
- 이미 있는 번역(모드에 포함된 번역, 번역 패치)은 그대로 두며 덮어쓰지 않습니다.

> 개인정보: 번역할 모드의 글은 사용 중인 AI 어시스턴트의 제공업체로 전송됩니다.

## 필요한 것

- RimWorld 1.7(한 번 이상 실행한 적이 있어야 합니다).
- MCP를 지원하는 AI 어시스턴트(예: Claude 데스크톱 앱).

## 세 단계

### 1. 브리지 모드 설치(권장)

창작마당에서 "Agent Translation Bridge"를 구독하고 모드 목록에서 활성화합니다(위치는 상관없습니다). 이 모드는 다음을 합니다.
- 간단한 사용법, 번역 상태, 번역 팩 언어를 모은 설정 페이지를 보여 줍니다.
- 게임 안에서 각 번역이 실제로 적용되었는지 확인합니다.
- 설정 페이지를 여는 버튼 두 개를 추가합니다. 하나는 오른쪽 아래 아이콘 줄의 작은 아이콘(Harmony 모드 필요), 다른 하나는 아래쪽 탭 막대의 작은 버튼입니다. 둘 다 설정 페이지에서 숨길 수 있습니다.

### 2. rwat 설치 후 AI 어시스턴트에 연결

프로젝트 릴리스 페이지에서 `rwat.exe`를 내려받아 정해진 폴더(예: `D:\Tools\rwat\`)에 둡니다.

파일이 변조되지 않았는지 확인하려면 PowerShell에서 다음을 실행합니다. 결과가 릴리스 페이지의 `SHA256SUMS.txt`와 같아야 합니다.

```
Get-FileHash rwat.exe -Algorithm SHA256
```

**Claude 데스크톱 앱**:
1. "Settings > Developer > Edit Config"를 엽니다.
2. 아래 내용을 추가하고, `command`를 rwat.exe를 둔 위치로 바꿉니다.
3. 저장한 뒤 Claude를 다시 시작합니다.

```json
{
  "mcpServers": {
    "rimworld-translation": { "command": "D:\\Tools\\rwat\\rwat.exe", "args": ["serve"] }
  }
}
```

Claude 데스크톱 앱의 Code 탭도 이 설정을 사용하므로, 설정은 한 곳에만 하세요.

**Claude Code**: 다음 한 줄을 실행합니다.

```
claude mcp add rimworld-translation -- "D:\Tools\rwat\rwat.exe" serve
```

**다른 MCP 클라이언트**: 설정 방법은 같습니다. 명령은 `rwat.exe`, 인수는 `serve`입니다.

rwat은 게임 폴더, 창작마당 폴더, 모드 목록을 스스로 찾습니다.

### 3. AI 어시스턴트에게 요청

번역 팩 언어는 기본적으로 게임 언어를 따릅니다. 먼저 게임 언어를 정하고, 설정이 저장되도록 게임을 한 번 종료하세요. 그런 다음 AI 어시스턴트에게 예를 들어 이렇게 요청합니다.

> 활성화된 모드 중 아직 한국어가 없는 모드를 번역하고 번역 팩을 만들어 줘.

끝나면 게임을 다시 시작하고 모드 목록에서 "Agent Translation Pack"을 활성화합니다. 번역한 모드 뒤에 자동으로 정렬됩니다.

## 설정 페이지

버튼을 누르거나 "옵션 → 모드 설정 → Agent Translation"에서 엽니다.

**간단 모드**(기본)는 대부분의 플레이어에게 필요한 항목만 보여 줍니다.
- 3단계 사용법
- 현재 상태(적용된 번역 수와 다음 할 일)
- 번역 팩 언어(메뉴. 대부분은 "게임 언어 따르기"를 고르면 됩니다)
- 버튼 두 개의 표시 여부

**고급 모드**는 다음 항목을 더 보여 줍니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| 실행 중 보고서 작성 | 켬 | 어떤 번역이 적용되었는지 확인합니다 |
| 재시작 없이 Keyed 번역 다시 불러오기 허용 | 끔 | 실험적. UI 문자열만 바뀌며, 이름과 설명은 여전히 재시작이 필요합니다 |
| 모드가 정의하지 않은 키도 번역 | 끔 | 영어에서도 `Some.Key.Name` 같은 키 이름이 그대로 보이는 모드가 있습니다. 켜면 AI 어시스턴트가 키 이름으로 문장을 추측하며, 모두 추측으로 표시됩니다 |
| 번체 모드: 기존 간체 번역 자동 채택 | 끔 | 기존 간체 번역을 번체로 바꿔 바로 사용합니다. 조건은 config.json에서 조정할 수 있습니다 |

- 고급 모드에서는 전체 보고서도 보여 줍니다.
- 버튼과 게임 내 확인 설정은 바로 적용됩니다.
- 번역 팩 언어와 마지막 두 설정은 rwat 설정 파일에 저장되며, AI 어시스턴트를 다시 시작하면 적용됩니다. AI 어시스턴트가 대신 바꿀 수는 없습니다.
- 설정 파일 위치: `%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\AgentTranslation\config.json`(게임의 `Saves`, `Config` 옆).

## 자주 묻는 질문

- **번역이 보이지 않습니다**:
  - 게임 언어와 번역 팩 언어가 같은지 확인하세요.
  - "Agent Translation Pack"이 활성화되어 있는지 확인하세요.
  - 설정 페이지에 다음 할 일이 표시되고, 고급 모드에서는 번역이 적용되지 않은 모드 목록을 볼 수 있습니다.
- **언어를 바꾸려면**: 설정 페이지에서 언어를 고르고(또는 게임 언어를 바꾸고), AI 어시스턴트를 다시 시작한 뒤 번역 팩을 다시 만들어 달라고 하고, 게임을 다시 시작합니다.
- **실험적 언어**: 자리 표시자, 태그, 줄바꿈은 검사하지만 그 언어 전용 검사는 없습니다. 게임 안에서 결과를 확인해 주세요.
- **제거**: Mods 폴더의 `!AgentTranslation_Pack`을 삭제합니다. 원하면 브리지 모드 구독을 해제하고 위의 `AgentTranslation` 폴더도 삭제하세요.
- **품질**: 번역은 기계 번역이며 사람이 검수하지 않았습니다. 용어를 맞추고 싶다면 번역 메모리나 용어집을 쓰도록 AI 어시스턴트에게 요청하세요.
